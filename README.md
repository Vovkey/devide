# DEVIDE

_An algorithmic art generator._

It has 3 different algorithms:

1. Rectangles.
2. Triangles
3. Branching

They create different kinds of shapes and look cool.

There are 5 different colour themes to cycle through.

You can view your artwork with F11 and save it as a png with crtl + s.

There are different settings in the sidebar to fool around with the shapes.
